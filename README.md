# mdview

A two-pane markdown previewer. Paste or load a file on the left, and the live preview appears on the right.

## Open

In a browser:

`http://localhost/fourwit-packages/mdview/readme-doc-generator.html`

## Load markdown

Use any of these:

- Paste markdown into the left pane
- Drop a `.md` file onto the left pane
- Click **Open** and pick a file
- Paste a file path (for example `/home/ubuntu/.cursor/plans/example.plan.md`) and press **Enter** or **Load**

## Preview

- **− / +** zooms the preview (click the percent to reset)
- The expand button fullscreens the whole preview
- **Copy** copies a code block
- **Fullscreen** on a diagram or table opens that block by itself (Escape or Close to leave)

Only `.md`, `.markdown`, `.txt`, and `.mdx` files can be loaded from a path.
